Eagle Business Dashboard — User Manual v1.0.33

This document describes the user-visible functions and normal operating behavior of the module for Odoo 18.

Navigation

Use Business Dashboard → Dashboard to access the Operation, Business, and Finance dashboards. The Operation dashboard is the default dashboard.

Operation Dashboard

The Operation dashboard contains Sales, Purchases, Quotations, RFQ, and Transactions. Each table can be folded/unfolded. Table headers can be used for presentation sorting. Record references and partners open their related Odoo records.

Operation Dashboard Quick Sale

The floating + button opens the Quick Sale dialog. The dialog is separate from the dashboard display so typing into the Product field does not re-render the dashboard.

Product search

Type at least two characters. Search results are retrieved from Odoo and can be selected by clicking a result. Search matches product name, internal reference, or barcode. The result list is limited to the first 30 matches for the current query.

Keyboard controls: Arrow Down/Arrow Up move through results; Enter selects the highlighted result; Esc closes the result list or dialog.

Order creation

Select a product, enter a quantity greater than zero, optionally select a partner, and choose Create Order. Odoo creates or updates a draft sales order according to the module's Quick Sale rules, then the order opens for review.

Finance Dashboard

The Finance dashboard contains invoices, vendor bills, transactions, journal balances, journal balance summary, transfers, reconciliation information, and related financial controls. Financial sections may be folded by default.

Ledger Balance Security

When a journal is configured to mask balances, Previous and New Balance values are hidden from users who are not explicitly approved for that journal. Deposit, Withdraw, and Change remain available for transfer monitoring. Approval for a protected journal is separate from the user's administrator role.

Partial Cash Balance Display

For a user who is not approved to view one or more protected ledgers, Cash Balance, Opening, and Balance show only the unprotected portion when other visible ledger contributions remain. The visible amount is followed by *. If all contributing ledger accounts are protected, the aggregate remains masked. In and Out movement totals remain visible for transfer checking.

Printing and Export

Finance reports and CSV exports apply the same ledger-balance masking rule used by the dashboard. Operation Dashboard printing is controlled through its print wizard.

Payment Form

The standard Odoo payment form uses a light red background for Send/Outbound and a light green background for Receive/Inbound. The tint follows the live Payment Type control and is presentation only.

Customization

Where enabled, users can customize dashboard density, sections, refresh behavior, theme, and workspace. Administrator-controlled security rules take precedence over personal visibility settings.

Quick Sale Search Troubleshooting

After a module upgrade, restart Odoo and perform a hard browser refresh (Ctrl+Shift+R). If Product search still fails, check the browser console and the Odoo server log for errors from dashboard.data.get_product_options.

Data and Security

The dashboard is a presentation and navigation layer over Odoo. It does not replace Odoo's native accounting, sales, purchasing, or inventory workflows.

Quick Sale

Quick Sale is a standalone dialog. Partner selection uses server-side type-ahead search by partner name, reference, email, or phone. Product selection uses server-side type-ahead search by product name, internal reference, or barcode. Search results are bounded and clickable. The Create / Add to Order action remains visible after product selection and submits the selected product and quantity to the server.

Quick Sale action controls: Cancel and Create Order are created programmatically with isolated styling so both remain visible and clickable regardless of generic Odoo button styling.

Quick Sale actions

The primary Create Order action and Cancel action are rendered inside the visible Quick Sale form body. They do not depend on the Odoo modal footer. The primary action is available after a valid product selection and remains visible during search and validation states.

Operation Dashboard document actions

Sales and Purchase headers include New actions and print-wizard actions. The Sales print wizard covers Sales Orders and Quotations. The Purchase print wizard covers Purchase Orders and RFQs. The Quotations and RFQ cards no longer have separate print/export buttons.

Operation Dashboard transactions

The Transactions header provides Receive and Send actions. Receive opens a new inbound Odoo payment and Send opens a new outbound Odoo payment. These actions create standard Odoo payment forms and do not post or confirm them automatically.

Payment form direction theme v1.0.33

The standard account.payment form is tinted light red for Send/Outbound and light green for Receive/Inbound. The primary implementation is CSS-based and reacts directly to the checked payment_type radio, with a minimal JavaScript fallback for DOM variants. This does not change payment or accounting behavior.

Transaction CSV export v1.0.35

The Operation Dashboard transaction CSV includes separate Receive and Send columns. Receive contains inbound payment amounts and Send contains outbound payment amounts. Transaction print tables use the same separate columns. The exporter no longer combines the two directions into a single Amount column.

Transaction columns v1.0.35

Transaction tables and transaction CSV/print outputs use separate Receive and Send columns. Receive contains inbound payment amounts; Send contains outbound payment amounts. A transaction has a value in the applicable direction column and zero/blank in the other direction, according to the source data.
