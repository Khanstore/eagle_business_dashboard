1. Getting Started

  1. Install or upgrade Advanced Business Dashboard from Apps.
  2. Open Business Dashboard from the main Odoo menu.
  3. Use the top navigation to switch between Business, Finance, and Operations.
  4. Use the date filters to limit dashboard calculations to a period.
Tip: Dashboard numbers are read from your Odoo records and respect the current user's Odoo access rights.

2. Business Dashboard

The Business dashboard provides a consolidated view of sales, purchasing, inventory and financial activity.

Common actions

  • Review KPI cards and open their underlying Odoo lists.
  • Filter by date and partner.
  • Review quotations, sales orders, purchase orders/RFQs and transactions.
  • Use KPI comments for internal notes.
  • Review low-stock information and snooze a low-stock product when the feature is available.
  • Use the visibility settings to control dashboard sections shown to you.

3. Finance Dashboard

The Finance dashboard focuses on invoices, vendor bills, payments, journals and finance controls.

  • Review customer invoices and residual amounts.
  • Review vendor bills and residual amounts.
  • Review payment transactions and their status.
  • Use Receive for inbound payments and Send for outbound payments.
  • For draft payments, use Validate to confirm the payment through the dashboard action.
  • Review journal balances and transaction details.
  • At the very bottom of the Finance dashboard, the Journal Balance Summary table is always available and shows every bank/cash journal with Previous, Deposit, Withdraw, Change and New Balance.
Payment note: Validation changes an accounting payment. Confirm the payment details before validating it.

Journal Balance Summary: This table is a dedicated bottom-of-Finance-dashboard section and is enabled by default for all dashboard roles. It is separate from the optional full Journal Balance drill-down section. It shows each bank/cash journal with Previous, Deposit, Withdraw, Change, and New Balance. Previous is the balance before the selected period. Deposit and Withdraw follow the same amounts used in the printable Journal Balance table, while Change is Deposit minus Withdraw and New Balance is Previous plus Change. All Finance-dashboard tables are folded by default; click the chevron on a table card to expand or collapse it.

Journal Balance drill-down: The Journal Balance table is folded by default. After opening the table, each journal row is also folded. Click a journal row to expand it inline and see the transactions belonging to that journal for the selected period. The expanded list includes reference, date, partner, deposit, withdraw and status, with totals for the journal. Click the same row again to collapse it.

Ledger Balance Security: Dashboard Admins can mark selected bank/cash journals as confidential. For a masked journal, Previous and Current balances are displayed as •••••• to users who are not approved. Change remains visible to everyone so users can compare transfers and period movement. The administrator can approve individual users per journal from Business Dashboard → Finance Dashboard → Settings → Ledger Balance Security, or use the Ledger Security button in the Finance Dashboard header. Approved users see the actual balances; Dashboard Admins always see them. When at least one journal is protected for the current user, the aggregate Cash Balance and Cash Flow balance figures are also masked to prevent the hidden journal balance from being inferred from a total.

5. Quick Sale

The Quick Sale floating action button opens a compact sales entry window.

  1. Click the Quick Sale button.
  2. Type in the Customer field to search customers.
  3. Type in the Product field to search products.
  4. Select a valid search result rather than leaving an arbitrary text value.
  5. Enter quantity and, where supported, a unit price.
  6. Create the sale.
Type-to-search: Customer and Product selectors are designed for typing/searching rather than scrolling through long lists. The Quick Sale product search now queries the full active, saleable product catalog on the server, so products beyond the old 300-item browser list can also be found. You can search by product name, internal reference, or barcode. The interface shows a small set of matching results for performance, but the search itself is not limited to the first 300 products.

7. Sales and Purchase Workflow

The dashboard is intentionally read-only for sales and purchase document progression. There is no dashboard button that automatically confirms a quotation/RFQ, completes a delivery/receipt, and creates/posts an invoice or vendor bill.

Use the normal Odoo Sales, Inventory, Purchase and Accounting screens to perform each step so stock availability, approvals, taxes, quantities, lot/serial numbers, invoicing policy and payment controls are reviewed at the appropriate stage.

Why: Keeping these steps separate reduces the risk of accidentally confirming commitments, completing stock transfers, or posting accounting documents from a single dashboard click.

8. Payment Validation Button

The Validate button is shown for both Draft and In Process payment rows.

  • Draft: Validate posts the payment using Odoo's payment action.
  • In Process: the payment is already posted. The button remains visible for a consistent workflow, but Odoo requires bank matching/reconciliation before the payment can move to Paid.

10. Ledger Balance Security

Use this control when some bank/cash balances should be visible only to selected users while transfer differences remain visible to the wider team.

  1. Open Business Dashboard → Finance Dashboard → Settings → Ledger Balance Security, or use the Ledger Security button in the Finance Dashboard header as a Dashboard Admin or Odoo Administrator.
  2. The screen lists the bank/cash journals and lets you open each security rule.
  3. Turn on Mask balances for the required journal.
  4. Select one or more approved users.
  5. Save the record.

Unapproved users see •••••• for Previous and Current. The Change figure remains visible. Dashboard Admins and Odoo Administrators always retain access. The Finance Dashboard header also provides a direct Ledger Security button for authorized administrators.

10. Exports, Snapshots and Sharing

  • Export supported dashboard tables to CSV.
  • Generate a printable/report-style dashboard view where available. The printed Journal Balance table is evaluated for the user who clicks Print: approved users and Dashboard/Odoo Administrators see Previous/New Balance, while unapproved users see ••••••; Deposit, Withdraw and Change remain visible.
  • Create a read-only snapshot link from the Business dashboard.
  • Snapshot links are time-limited; the current implementation creates them with a default validity period of 48 hours.
Snapshot security: Treat a snapshot link as shareable access to the snapshot contents. Do not publish it publicly if the snapshot contains confidential business information.

12. Troubleshooting

Module upgrade error: If an administrator menu reports that the Ledger Balance Security action XML ID cannot be found, upgrade to a build where the ledger security action is defined before the menu items that reference it. This is a module XML load-order issue, not a database-balance issue.

  • Dashboard does not load: refresh assets after upgrading the module and check the Odoo server log for JavaScript/Owl errors.
  • Search result not selectable: type more characters and choose a result from the search list.
  • Payment action fails: check that the payment is eligible for the requested action and that the user has the required Accounting permissions.
  • Numbers look different from an Odoo list: check the dashboard date/partner filters and the user's company/access context.
  • Snapshot expired: create a new snapshot link.
  • Partner or transaction link error: after upgrading, hard-refresh assets so the Business Dashboard loads the current navigation handlers; the root dashboard now defines openPartner() and openTransaction().

This manual describes the functionality implemented in the supplied Advanced Business Dashboard module. Odoo Accounting, Sales, Purchase and Inventory permissions remain authoritative.

Journal Balance — Per-Journal Transactions

The Journal Balance and Journal Balance Summary tables keep each journal row collapsed. Click anywhere on the journal row or the chevron to expand it. The dashboard then loads that journal's payment transactions from the server for the selected date range. Click again to collapse the journal.

The expanded transaction list shows Reference, Date (when applicable), Partner, Deposit, Withdraw and Status. Payment references remain clickable. Refreshing the dashboard or changing the date range clears the expanded rows.

Finance print report: line-item headers

In the printed Finance Dashboard, the Product column header remains left-aligned. Qty, Rate, Disc%, Tax, and Total headers are right-aligned to match their numeric/detail columns.

Journal transaction validation

When Journal Balance or Journal Balance Summary is expanded, draft and in-process payment transactions display the same Validate button available in the main Transactions table. The button calls the dashboard payment-validation method, then refreshes the finance data. Paid transactions do not show the button.

Payment Validate Button — Journal Drill-down

The Journal Balance and Journal Balance Summary drill-down uses the same Validate action as the main Transactions table. Draft, in-process, and paid journal payments can be displayed; Validate is shown for draft and in-process entries. Draft payments can be posted. In-process payments are already posted and may require reconciliation or bank matching.
