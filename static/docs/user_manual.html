Eagle Business Dashboard — User Manual v18.0.10.11.24

This document describes the functions and operating behavior of the Eagle Business Dashboard for Odoo 18.

Version 18.0.10.11.23 — Operations table controls

The Operations Dashboard Orders and Purchase tables now use reactive folding and sorting. Click the table title/chevron to fold or unfold; click any column heading to sort ascending, then descending. Sort choice and open/closed state are preserved in the browser and remain correct after dashboard updates.

Navigation

Use Business Dashboard → Dashboard to access Business, Finance, and Operations. The Operations page is a dedicated operational workspace with Orders, Purchase, Quotations, RFQ, Transactions, Delivery Orders, Receiving Orders, Internal Stock Transfer, filters, quick actions, and Team Notes. The Finance dashboard contains invoices, vendor bills, Journal Balance, Journal Balance Summary, transfers, reconciliation information, cash-flow information, and related finance panels.

Journal Balance

The Journal Balance table contains Journal, Previous Balance, Deposit, Withdraw, Change, and New Balance. The table can be folded/unfolded. Journal rows can expose their related payment transactions when expanded.

Ledger Balance Security

Ledger Balance Security controls the visibility of the Previous and New Balance values for individual bank and cash journals.

For a journal with Mask balances enabled, a user must be explicitly listed under Approved Users to see that journal's balance. Dashboard Admin and System Administrator status grants permission to configure the security rule; it does not automatically bypass the rule.

For an unauthorized user, the journal's Previous and New Balance are masked. Deposit, Withdraw, and Change remain visible.

Cash Flow Aggregate With Protected Ledgers

The Finance Dashboard Cash Flow card uses the same journal-level visibility rules. When some, but not all, contributing bank/cash ledgers are protected, the dashboard shows the visible aggregate only for Opening and Balance, followed by an asterisk (*).

For example, if the real aggregate is BDT 100,000 and BDT 10,000 belongs to protected ledgers, an unauthorized user sees BDT 90,000*. The protected amount is not sent to the browser.

SituationDisplayed Opening / Balance
No protected contributing ledgerFull value
Some protected contributing ledgersVisible value*
All contributing ledgers protected••••••

The asterisk means: some protected values are excluded. In and Out remain visible as cash-movement totals for transfer checking.

Configuring a Journal

Open Business Dashboard → Settings → Ledger Balance Security. Select a journal, enable Mask balances, select the users who may see the balance, and save the configuration.

Operations Workspace

The Operations menu opens the dedicated Operations workspace. It uses the same Eagle dashboard styling and shared date/partner filter state as the other dashboards. Orders, Purchase, Quotations, RFQ, Transactions, Delivery Orders, Receiving Orders, and Internal Stock Transfers can be opened from the workspace. Internal Stock Transfer displays source and destination locations, creation and scheduled timestamps, status, and responsible user. New Sales Order, New Purchase Order, Receive Money, Send Money, Quick Sale, and Quick Internal Transfer actions are available directly from the page. Use Quick Internal Transfer to select internal source and destination locations, choose a stockable/consumable product and quantity, create a transfer, and open it for review.

Testing

Use a non-administrator account that is not listed as an Approved User to verify masking. Use a second account that is explicitly approved to verify unmasked visibility. To verify partial aggregate masking, protect one contributing journal and leave at least one other contributing journal visible.

Printing and Export

Journal Balance printing and CSV export apply the same user-specific ledger visibility rule.

Sales Trend Graph

The Sales Trend panel is a graph rather than a simple bar list. Date-dependent Business Dashboard highlights, including Selected Period Highs & Lows, refresh whenever the From/To range changes. Use the View by controls to switch between Day, Week, Month, Quarter, and Year. The selected scale is requested from the server and the graph fills periods with zero sales so that gaps remain visible on the time axis.

The graph automatically scales its Y-axis to the highest value in the selected range. Hovering a point shows the period and exact sales amount. The total shown above the graph is the sum of the periods returned for the selected scale.

Dashboard Tables

Dashboard tables support folding/unfolding and sorting of displayed columns where table controls are available.

Payment Transaction Actions

In the Finance transaction tables, a Validate button is shown only for draft payments. For payments already in In Process, the dashboard shows Match instead. Selecting Match opens the standard Odoo payment record so the payment can be completed through the normal bank matching or reconciliation workflow. An In Process payment is already posted; it must not be posted again.

Dashboard Record Actions

The Business Dashboard Transactions area provides Receive and Send buttons that open the standard Odoo payment form with the appropriate payment direction. The Orders and Purchases tables also provide New buttons for creating a sales order or purchase order. These buttons use standard Odoo forms and workflows.

Quick Order

Quick Order searches the product catalog on the server by product name, internal reference, and barcode.

Dashboard Role Assignment

Dashboard roles are assigned per Odoo user. Open Settings → Users & Companies → Users, open the user, and use the Access Rights tab. The Business Dashboard section contains Dashboard Admin, Dashboard Manager, and Dashboard User.

Customization

User preferences can control layout density, theme settings, visible sections, refresh interval, and related display options. Administrator security restrictions take precedence over personal visibility preferences.

Owl Event Handlers

Action buttons are backed by named component methods so the Business Dashboard does not reference undefined handlers. The New Order, New Purchase, Receive, and Send actions are available from the dashboard.

Updates

After upgrading the module, restart Odoo when required and refresh the browser assets with a hard refresh.

Payment Form Appearance

static/src/js/payment_form_theme.js applies presentation-only styling to Odoo 18 payment forms. The styling does not provide any security boundary.

Operations Dashboard — Delivery Orders

Version 18.0.10.11.16: Delivery Orders now show Carrier and Tracking Reference. When a Delivery Order has no tracking reference, the Operations Dashboard provides an inline field where the user can enter and save one. Existing tracking references are displayed read-only in the dashboard. The Status value is an action button while the transfer is not Done or Cancelled; clicking it runs the standard Odoo picking validation workflow. Done and Cancelled transfers remain non-action badges.
