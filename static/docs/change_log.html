Eagle Business Dashboard — Change Log

18.0.10.11.24

  • Standardized fold/unfold and sortable column behavior across Business, Finance, and Operations dashboard tables.
  • All tables start folded after upgrade; unique table cards fold from the title/chevron, while nested/multi-table panels use individual fold controls.
  • Added versioned fold-preference keys to reset the default folded state while preserving existing sort preferences and new user choices thereafter.

18.0.10.11.23

  • Made Operations Orders and Purchase folding reactive and reliable using Owl-managed state.
  • Added functional sorting for every visible column with ascending/descending icons and persisted preferences.
  • Disabled duplicate DOM listeners on the component-managed tables to prevent click controls being reverted during Owl patches.

18.0.10.11.22

  • Business and Operations now use the same Quick Sale floating button style and the same reusable Quick Sale wizard.
  • Unified sortable-column persistence across the dashboard tables and stabilized fold/sort preference keys across conditional rendering.
  • Updated manuals and bumped the module version.

18.0.10.11.21

  • Added a Quick Internal Transfer floating action beside Quick Sale on the Operations Dashboard.
  • Added location/product search and a server-side workflow to create, confirm, and reserve an internal stock transfer.
  • Opening a transfer refreshes only the matching Operations row; table sort preferences now reapply after Owl updates and folding remains enabled.

18.0.10.11.20

  • Added an Internal Stock Transfer table to the Operations Dashboard with source/destination locations, creation/scheduled datetime, status, and responsible user.
  • Integrated internal transfers with the existing creation-date-or-done-date filter and targeted status refresh workflow.
  • Kept folding, sorting, CSV export, and standard Odoo picking validation behavior.

v1.0.11.10

  • Added a standalone Operations workspace opened from Dashboard → Operations, with the Eagle dashboard look and Orders, Purchase, Quotations, RFQ, Transactions, Delivery Orders, Receiving Orders, filters, and quick actions.
  • Moved Ledger Balance Security to the new Business Dashboard → Settings → Ledger Balance Security administrator menu.
  • Removed the Ledger Balance Security configuration block from the Finance dashboard settings modal.
  • Updated user and developer manuals.

v1.0.11.9

Selected Period Highs & Lows now reload with every From/To date-range refresh. The range-dependent best/slowest sales-day RPC is part of the main load cycle so stale values are not retained after changing filters.
